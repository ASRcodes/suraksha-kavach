# SatHack demo checklist

Use only URL strings, the harmless EICAR test and the no-code permission APK. Never open a suspicious link or install the dummy APK.

## Before presenting

1. Install the same tested debug APK. Complete notification access and notification permissions. Allow full-screen access if the phone supports it, or opt into the unlocked-screen overlay.
2. Select Hindi or Punjabi and press Hear a sample. Set an audible notification volume and review the wording with a fluent speaker.
3. Keep explicit Demo mode OFF. The demo must use the real models.
4. If demonstrating guardian SMS, obtain the guardian's consent, save their number, enable SMS and grant permission. Choose a default SMS SIM. An SMS attempt is limited to once per 30 minutes, including failed attempts and restarts.
5. Save a family code word privately. Prepare the harmless files without installing the dummy APK.
6. Open the held-out metrics report. Call them dataset results and show the small/synthetic Punjabi caveat.

## Suggested demonstration

1. Check an ordinary YouTube or Google URL. Show that no warning or voice appears.
2. Settings > Simulate > held-out Hinglish example, with Demo mode OFF. Show the real red verdict, reasons, local voice and guardian dial button.
3. With working SMS service and explicit opt-in, confirm the guardian receives only the generic warning. Do not claim delivery merely from the app's sent status.
4. Turn on airplane mode. Repeat a held-out sample; show the local warning and activity log. Explain that carrier SMS needs working service.
5. Share the harmless EICAR test file: show its distinct test explanation and no guardian SMS.
6. Share the no-code permission APK, without installing it. Rename it to ordinary.zip and repeat to show permission-based detection.
7. Check a normal file. Explain the limited No known warning signs result.
8. Open I'm on a suspicious call. Show the code-word question and the instruction to hang up and call the saved number, even after a matching answer.
9. Show Activity: verdict, domain/file label and time only. Show Enhanced mode OFF and the clear-all-data confirmation.

## Still requires the physical phone

- Real SMS/WhatsApp notification previews and background behavior.
- Carrier delivery and dual-SIM behavior.
- Lock-screen/full-screen/overlay permissions, DND and volume.
- Native-speaker audio review and large-text readability.
- SAF folder access and battery-delayed watcher behavior.
- Under-200-ms timing on the actual phone.

## If a permission blocks the demo

Open the app's permission setup. For sideloaded builds Android may require Allow restricted settings in the app's system settings before notification access can be enabled. If Android shows an urgent notification instead of opening the red screen, tap it. Manual checks use the same detector and still work offline.
